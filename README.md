# 選戰狂人夢 Election War

> 貨出得去、票進得來，凍蒜！

一款回合制的台灣選戰諷刺網頁遊戲。選一位身懷特殊能力的候選人，靠造勢、募款、爆料和防禦，在投票日拿下最多選票。

## ▶ 立即開玩

**https://dongsuan-studio.github.io/Election-War/**

不用安裝、不用註冊，手機和電腦的瀏覽器都能直接玩。

## 遊戲特色

- **16 位候選人**：7 位台灣政壇、9 位國際與歷史人物，各自有被動能力、專屬技能，以及造勢、爆料、防禦的個人特色。
- **爆料三步驟**：準備爆料素材 → 找管道 → 發動，對手可以用轉移焦點、澄清記者會、提告來防禦。
- **落後也能翻盤**：同情票回流、「告急」機制，最後一名也有逆轉機會。
- **自由設定**：對手 3～5 人、簡單／普通／困難三種難度、12 回合（快節奏）或 20 回合。
- **12 項成就**和結算時的 8 項排行。
- **分享號外**：結算後一鍵產生「選戰狂人夢日報」號外圖，附 QR code，可以直接傳 LINE、IG。
- **種子碼**：輸入相同種子碼，可以重現同一局，約朋友挑戰同樣的局面。
- 內建新手教學和音效，整個遊戲只有一個 HTML 檔。

## 怎麼玩

1. 選一位候選人，設定對手人數、難度和回合數。
2. 每回合選一個行動：
   - **造勢**：從中間選民或對手手上挖票。
   - **募款**：累積獻金，準備爆料、找管道和防禦都要花錢。
   - **部署防禦**：預防下一次被爆料。
   - **準備爆料 → 找管道 → 發動爆料**：素材要搭配對的管道才能發動。
   - **角色技能**：每位候選人的獨門絕招，有冷卻時間或使用次數限制。
3. 所有人同時出招、同時結算。
4. 投票日當天票數最多的人當選。

遊戲中右上角的「？」可以隨時重看玩法說明。
